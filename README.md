# Médias Instagram

Images et vidéos mises en ligne le temps qu'Instagram les télécharge au moment d'une publication.

- Ce dossier est **public** (GitHub Pages). Il ne contient que des fichiers déjà destinés à Instagram.
- Il est rempli automatiquement par `../instagram/insta.py publier` (sous-dossier `insta/`).
- Ne rien y ranger d'autre : ni le kit, ni `.env`, ni documents personnels.
- Une fois une publication en ligne sur Instagram, son sous-dossier dans `insta/` peut être supprimé.
